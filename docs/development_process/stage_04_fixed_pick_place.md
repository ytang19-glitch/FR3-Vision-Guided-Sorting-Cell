# Stage 4 — Fixed-Position Pick and Place

Add a known bin pose:

```text
HOME
  → PRE_GRASP
  → OPEN
  → DESCEND
  → CLOSE
  → LIFT
  → MOVE_TO_BIN
  → RELEASE
  → HOME
```

Repeat this sequence at least ten times before adding vision.
